# EcoStock

EcoStock là nền tảng giúp giảm thiểu lãng phí thực phẩm và tối ưu hóa chuỗi cung ứng, kết nối người tiêu dùng, cửa hàng, doanh nghiệp và tổ chức từ thiện.

## 🚀 Tính năng chính
- Đăng ký/Đăng nhập cho nhiều vai trò: Người tiêu dùng, Cửa hàng tạp hóa, Doanh nghiệp, Tổ chức từ thiện
- Giao diện hiện đại, thân thiện, responsive
- Đăng nhập/Đăng ký nhanh bằng Google
- Quản lý tài khoản, OTP xác thực số điện thoại
- Tối ưu trải nghiệm cho từng nhóm người dùng

## 🖥️ Công nghệ sử dụng
- Next.js 14 (App Router)
- TypeScript
- TailwindCSS
- Framer Motion (motion/react)
- Lucide React Icons

## 📦 Cài đặt & chạy dự án

```bash
# Cài dependencies
npm install

# Chạy server phát triển
npm run dev

# Truy cập: http://localhost:3000
```

## 📁 Cấu trúc thư mục
```
src/
  app/           # Các trang chính (login, register, marketing...)
  components/     # Component UI, layout, features
  constants/      # Các hằng số cấu hình
  hooks/          # Custom hooks
  lib/            # Hàm tiện ích
  services/       # API services
  types/          # Định nghĩa kiểu dữ liệu
public/
  img/            # Ảnh logo, hình nền
```
